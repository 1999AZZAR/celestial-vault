01. ARCHIVAL_ASTROMETRY_OVERVIEW

Celestial Vault is an archival procedural astrometry synthesis engine and vector planisphere repository designed according to the Swiss-Archival design system. Drawing upon historical astrometry from Hevelius's Prodromus Astronomiae (1690), Bayer's Uranometria (1603), and Su Song's 11th-century star charts, the engine procedurally synthesizes celestial coordinate systems, stereographic equatorial projections, constellation asterisms, and star catalog magnitudes using deterministic mathematical seeds.

02. PROCEDURAL_ASTROMETRY_LOGIC

By injecting narrative sequences into the matrix, the engine hashes the input to establish celestial epoch coordinates (Right Ascension & Declination), asterism topology via minimum spanning trees with cyclic closures, and catalog star field density. Every specimen is an immutable archival record, traceable via its accession identifier (e.g. CSV-DC-0019U5) and memory pointer hash.

03. ARCHIVAL_EXPORT_PROTOCOL

Specimens can be exported as high-resolution standalone SVG documents or 300 DPI PNG prints adhering to the Swiss-Archival design system. Each exported plate incorporates Swiss-Archival dual drafting borders, an Astrometric Scale Bar (60' Arc-Minute Rule), a Cinnabar Vermilion Seal Chop (朱砂印章 · 星纬典藏), and an authentic Hershey vector cursive Latin title.

04. EMBED_INTEGRATION_PROTOCOL

Celestial Vault functions as an embeddable service. Utilizing the mode=embed URL parameter, the interface is reduced to a strictly archival specimen view with a bone-colored background, optimized for iframe integration. Developers can control the synthesis engine in real-time via the postMessage API.

05. PROGRAMMATIC_ARCHIVAL_ACCESS

The engine exposes zero-dependency JavaScript access via window.CelestialDraw. Developers can synthesize astrometric specimens, extract telemetry metrics, and generate archival plates programmatically in Node.js or client-side environments.
