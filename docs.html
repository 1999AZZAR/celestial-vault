01 // ARCHITECTURAL OVERVIEW

Celestial Vault synthesizes 100% deterministic, vector-grade celestial star charts and stereographic planispheres adhering strictly to the Swiss-Archival standard. Drawing upon historical astrometry from Hevelius's Prodromus Astronomiae (1690), Bayer's Uranometria (1603), and Su Song's 11th-century star charts, the engine derives astronomical coordinate systems, stellar magnitudes, and constellation asterisms from input narrative seeds.

Each synthesized plate incorporates Swiss-Archival dual drafting borders, an Astrometric Scale Bar (60' Arc Rule), an Archival Vermilion Seal Chop (朱砂印章 · 星纬典藏), and an engraved Hershey simplex vector cursive Latin title.

02 // MATHEMATICAL ASTROMETRY & PROJECTIONS

The coordinate framework is constructed through the following procedural layers:

  • Stereographic Planisphere: The celestial sphere is projected onto an equatorial plane with radius \(R\). Concentric circles delineate parallels of Declination at 30°, 60°, and 75° North/South.
  • Right Ascension Radial Meridians: 24 hour circles radiating from the celestial pole at 15° intervals, with major 30° spokes accented with fine dashed hairlines.
  • Astrolabe Degree Limb: A dual-ringed outer perimeter calibrated with 360 degree tick marks (major intervals at 30°, minor at 5° and 1°) and numeric angular callouts.
  • Ecliptic Great Ellipse: Tilted elliptical orbit crossing the celestial sphere at an obliquity of \(23.44^\circ\), deterministically rotated to match the precessional epoch.
  • Asterism Generation: Constellation figures are linked using a greedy minimum spanning tree (MST) heuristic combined with closed geometric loop reinforcements.

03 // JAVASCRIPT API REFERENCE

The CelestialDraw global module exposes high-level synthesis and export primitives:

CelestialDraw.synthesize(seed, options)

const specimen = CelestialDraw.synthesize("Hevelius Uranographia Constellation Study", {
    width: 600,
    height: 600,
    palette: "vellum" // "vellum" | "cyanotype" | "obsidian" | "indigo" | "golden"
});

console.log(specimen.accessionId); // "CSV-38-04D9Z1"
console.log(specimen.constellation); // "Cygnus Borealis"
console.log(specimen.metrics.alphaMagnitude); // "0.45 mag"

CelestialDraw.generateSvgPlate(data, options)

const svgString = CelestialDraw.generateSvgPlate(specimen, {
    width: 1200,
    height: 1200,
    palette: "cyanotype"
});
// Outputs a complete standalone SVG document with borders, scale bar, and seal chop
