01. EXECUTIVE_ARCHITECTURE_OVERVIEW

Celestial Vault is an archival procedural generation engine synthesizing historical celestial planispheres, astrolabe retes, equatorial star charts, and constellation asterism plates. Drawing upon historical astrometry from Hevelius's Prodromus Astronomiae (1690), Bayer's Uranometria (1603), and Su Song's 11th-century star charts, the engine derives astronomical coordinate systems, stellar magnitudes, and constellation asterisms from input narrative seeds.

The engine outputs 100% deterministic vector SVG documents that incorporate stereographic planisphere projections, 360-degree astrolabe degree limbs, declination parallels, right ascension meridians, minimum spanning tree asterisms with Bayer Greek designations, Swiss-Archival dual drafting borders, an Astrometric Scale Bar (60' Arc-Minute Rule), a Cinnabar Vermilion Seal Chop (朱砂印章 · 星纬典藏), and an engraved Hershey cursive vector Latin title.

02. PROCEDURAL_SYNTHESIS_PIPELINE

The synthesis engine operates through five sequential phases:

  1. Narrative Seed Hashing: Computes a 32-bit FNV-1a hash from the narrative string to seed the isolated Mulberry32 PRNG deterministically.
  2. Celestial Coordinate Derivation: Derives celestial epoch (J1900.0 - J2100.0), Right Ascension ($0^h - 24^h$), Declination ($-88^\circ - +88^\circ$), precession drift, and constellation binomial name.
  3. Planisphere Projection & Limb: Projects declination circles (30°, 60°, 75°) and 24 radial hour meridians onto a stereographic equatorial disc, surrounded by a 360° calibrated astrolabe graduation limb and tilted ecliptic ellipse ($23.44^\circ$).
  4. Asterism Minimum Spanning Tree: Computes primary asterism nodes, constructs a Euclidean minimum spanning tree with structural polygonal loops, attaches Bayer Greek designations ($\alpha, \beta, \gamma \dots$), and populates ambient field stars with Gaussian luminosity distribution.
  5. Archival Framing & Calligraphy: Injects Swiss-Archival dual drafting borders (outer 1.0pt, inner 0.5pt), 60' Arc-minute astrometric scale rule, Cinnabar seal chop (星纬典藏), and engraved Hershey simplex vector cursive Latin title into the final SVG plate.

03. JAVASCRIPT_API_REFERENCE

Celestial Vault exposes a zero-dependency UMD module via window.CelestialDraw:

CelestialDraw.synthesize(seedInput, options)

Synthesizes a procedural astrometric specimen and returns all telemetry, star nodes, asterism edges, and metrics.

const specimen = CelestialDraw.synthesize("Ptolemaic Planisphere of the Northern Stars", {
  width: 1200,
  height: 800,
  palette: "vellum" // "vellum" | "cyanotype" | "obsidian" | "indigo" | "golden"
});

console.log(specimen.accessionId); // e.g. "CSV-DC-0019U5"
console.log(specimen.constellation); // e.g. "Corona Ecliptica"
console.log(specimen.metrics.coordinates); // e.g. "22h 50m 11s / +37° 31'"

CelestialDraw.generateSvgPlate(data, options)

Generates a complete standalone SVG document complete with archival borders, astrolabe degree limb, 60' scale rule, and vermilion seal chop.

const svgString = CelestialDraw.generateSvgPlate(specimen, {
  width: 1200,
  height: 800,
  palette: "cyanotype"
});
// Save to file or inject into DOM

CelestialDraw.renderToCanvas(data, canvas, options)

Renders the specimen onto an HTML5 canvas at any target resolution for high-resolution 300 DPI PNG export.

const canvas = document.createElement('canvas');
canvas.width = 2400;
canvas.height = 2400;
await CelestialDraw.renderToCanvas(specimen, canvas, {
  palette: "vellum"
});
const pngDataUrl = canvas.toDataURL('image/png');

04. EMBED_INTEGRATION_PROTOCOL

Add mode=embed to any Celestial Vault URL to enable distraction-free specimen rendering optimized for iframes: 

<iframe 
  src="https://celestial-vault.glassgallery.my.id/?id=CSV-DC-0019U5&palette=cyanotype&w=1&h=1&mode=embed" 
  width="100%" 
  height="600" 
  frameborder="0" 
  style="border:1px solid #DDD5C5; background:#EFE9DC;">
</iframe>

Dynamic postMessage Controller

// Send new astrometry parameters to embedded iframe
const iframe = document.querySelector('iframe');
iframe.contentWindow.postMessage({
  seed: "Hevelius Uranographia Constellation Study",
  palette: "obsidian",
  w: 16,
  h: 9
}, "*");
